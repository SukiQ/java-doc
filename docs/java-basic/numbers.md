# 数值


## 为什么不能用浮点数表示金额？

float/double 是 **IEEE 754 二进制浮点数**——用二进制科学计数法存储，而多数十进制小数在二进制下是**无限循环小数**，无法精确表示，只能近似存储。


- 方案一： **BigDecimal**  字符串构造 + 显式舍入模式，金额计算的主流选择
- 方案二：**整数分存储** 以"分"为单位用 `long`，如 999 元 = 99900，高性能场景、交易系统



## BigDecimal 怎么比较大小？

- **compareTo**：比较数值
- **equals**：比较数值和精度
